# PIM Event Control PWA v8.9

Frontend read-only untuk workbook Schema 2.0. Tidak menggunakan build system dan tidak memiliki `DEMO_DATA`.

## Konfigurasi
Edit `config.js` dan isi `API_URL` dengan URL Web App Apps Script terbaru. Sebelum URL diisi, aplikasi menampilkan **Backend belum dikonfigurasi**.

## Deployment
Unggah seluruh isi folder ini ke root GitHub Pages. Gunakan `?preview=1` untuk workbook berstatus `Ready for Validation`; cache preview dan production terpisah.
